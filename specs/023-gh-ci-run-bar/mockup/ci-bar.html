Scribe CI Bar

The bar is a timeline, not a status row. Collapsed, every job is a named cell with a live track; expanded, jobs become time-positioned bars. A badge-keyed underline ties the band to the workspace that owns it. Motion follows the existing GPUI animation policy (attention-flash lineage, honors the global off switch).

The live job's right edge breathes in the same rhythm as the collapsed dot. Per-job data is fetched only while the trace is open.

Terminal states

Success settles every track green and auto-clears after ~10 s. Failure names the broken job in red and re-keys the ownership underline semantic red — it persists until dismissed. Cancelled goes quiet. Stale amber-keys the underline, freezes elapsed and all motion, and names the retry. A square mark replaces the ring once the run is over; glyph + word always accompany color.

Reading the timeline

ring conic fill = jobs completed / total; a solid square mark replaces it on terminal states
job cell name over live track, one per job; workflow boundaries drawn as one-pixel rules. Breathing dot + full-foreground name = active, settled fill = done, dashes = queued, red name = failed. Beyond ~6 jobs the strip elides to failed + active jobs plus a “+n” counter cell
underline workspace badge color = ownership; re-keyed red on failure, amber on stale
trace bar job positioned on the shared time axis; the breathing right edge is the live frontier

Motion rules

  • Appear — 200 ms slide-down + one-shot light sweep; runs once per run, never loops.
  • Breathe / shimmer — one shared 1.2 s rhythm for the live dot, trace frontier, and edge caret; only while a job is live. Terminal states are fully static.
  • Success exit — tracks settle green, band slides up after ~10 s.
  • Policy — all motion routes through the GPUI animation system and its off switch; reduced-motion renders static fills.

Interaction rules

  • Appear — first run observation for your pushed head; a push that triggers no workflows never shows a bar.
  • Click / keybinding — toggles the trace; per-job data fetched only while open.
  • open ↗ — owning client only; omitted for shared viewers.
  • ✕ dismiss — hides this head's bar on every attached client; a new push resurrects it.
  • Colors — semantic states from the live theme's ANSI palette; ownership from the workspace badge palette; the band re-themes with the terminal.
