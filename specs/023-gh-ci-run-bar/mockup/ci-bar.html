Scribe CI Bar

Workspace-top chrome band tracking the GitHub Actions runs triggered by your own push. Every state below is a full-window vignette in Scribe's minimal-dark theme with its derived chrome colors.

06 · stale

API failure during an active run: last-known content is kept, elapsed freezes, and a yellow ⚠ names the degradation and the retry. Recovery resumes running; window expiry hides the band. Outside an active run, failures never surface a bar.

08 · shared viewer — read-only

LAN-share and remote-control viewers see the same band with the action cluster omitted: no open ↗, no dismiss. Rendering involves no token — viewers receive state, never credentials.

Glyph vocabulary — never color alone

◐ running active run; elapsed advances
◌ queued run/job accepted, not started
✓ passed terminal success; auto-clears after ~10 s
✕ failed terminal failure; persists until dismissed
⊘ cancelled terminal cancellation; persists until dismissed
⚠ stale API degraded mid-run; elapsed frozen, retry named

Interaction rules

  • Appear — first run observation for your pushed head; a push that triggers no workflows never shows a bar.
  • Click / keybinding — toggles the per-job panel; per-job data is fetched only while open.
  • open ↗ — opens the run on GitHub; owning client only, omitted for shared viewers.
  • ✕ dismiss — hides the bar for this head on every attached client; a new push resurrects it.
  • Colors — all from the live theme's ANSI palette and derived chrome; the band re-themes with the terminal.
