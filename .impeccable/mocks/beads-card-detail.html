The thread warms toward coral and ends at one junction node on the unblocks line, where the beads this one frees flow inline — sc-58, sc-36 — each clickable through, wrapping when there are more. A blocked issue reverses the picture — coral upstream nodes above, its own node lower on the thread.
  • Typeset ink, nothing boxed: the priority is bare ink in its heat colour — the same grammar as the Ready word — not a filled chip; the description leads unlabelled; acceptance and notes carry run-in small-cap heads; labels are words. Every passage is click-to-edit in place — hover lifts its ground and shows the caret, the same single-inline-editor pattern the settings window uses — and clicking the P1 mark unfolds the P0–P4 pick row in place. Commits run bd update and repaint the board.
  • Comments are the thread's correspondence, newest first: the latest clamped to two lines, every earlier one a single collapsed line — author · date · first words — expanding in place on click, so the whole thread is visible at one line per comment. "add a comment…" sits on the head row and posts via bd comment. Notes and comments stay distinct — notes is one editable field, the thread is append-only.
  • The footer is a rail, not a toolbar: the three writable statuses break the hairline the way lane heads break the board's rail, and only the live one carries a node — the others are just words, so nothing reads as a radio group; queues stay derived. The rail stops short of the action words — claim and close issue run the bd verbs.
