# crate ships far more implemented-and-unit-tested surface than the running
# binary can reach. tools/check-reachability.sh re-derives the numbers below
# from the source on every run and fails when they get worse.
#
# `counts` lines are the launch-gate metric. The `-total` numbers track the
# protocol and the module list; the `-wired` / `-handled` numbers track what the
# live binary reaches and may only go up.
#
# The remaining lines name every surface that exists in the crate but is not on
# a live path:
#
#   unwired-module            a `pub mod` in lib.rs that main.rs and its binary
#                             submodules never import
#   unhandled-server-message  a ServerMessage variant that reaches
#                             main.rs `dispatch_server_message` only to be
#                             counted and warned by `unhandled_server_message`
#   unhandled-layout-action   a LayoutAction variant the key path intercepts and
#                             hands to `unhandled_layout_action`
#
# Wiring one of these up means deleting its line here and bumping the matching
# count. Adding a line is a deliberate act that needs a bead to justify it.
